# vivek-sdfsdfss

A modern folder management tool organized using an MVC-style structure.

## Project Structure

```text
.
├── app.js
├── package.json
├── README.md
├── controllers/
│   └── folderController.js
├── models/
│   └── folderModel.js
├── routes/
│   └── folderRoutes.js
├── services/
│   └── folderService.js
├── views/
│   ├── index.html
│   ├── styles.css
│   └── app.js
└── data/
    └── folders.json
```

## Features

- Create folders
- View folder hierarchy
- Rename folders
- Delete folders
- Modern frontend layout
- MVC-style backend structure

## Run Locally

```bash
npm install
npm start
```

Open:

```text
http://localhost:3000
```
